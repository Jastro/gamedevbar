# Bundled Vircon32 games

Every `.v32` here is redistributed under its author's license (or, for Ocean Storm, with the author's
permission). Each was downloaded unmodified from the author's GitHub release, or from Carra's official
[CommunityContent](https://github.com/vircon32/CommunityContent) repository, on 2026-10-21. Add a game
only after checking that its license allows redistribution. List it here and in `roms.json`. Files
must stay under GitHub's 100 MB limit (no Git LFS).

Games marked "fuente de Vircon32 CC BY 4.0" include the TextureFont22x32 font by Carra (@vircon32),
CC BY 4.0, and Vircon32's DrawPrimitives/TextFonts libraries (BSD-3-Clause). The GPL-3.0 collections
(Gamebuino Classic, TinyJoypad) are combined works: their full source, including every included game's
original license and credits, is at the linked release.
